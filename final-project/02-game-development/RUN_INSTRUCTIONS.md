# Stage 2 Run Instructions

Updated: 2026-06-09

## Open The Project

From this repository, open the Unity project folder:

```text
final-project/FoxDash/
```

The local development copy used during editing was:

```text
/Users/zhuxuan/Downloads/FoxDash
```

Recommended editor:

```text
Unity 2022.3.62f3c1
```

A compatible Unity 2022 LTS editor should also work.

## Main Scene

Open:

```text
Assets/Scenes/Play.unity
```

Then press Play in the Unity editor.

## Main Menu Flow

1. Wait for the loading screen to finish.
2. Choose a character from the home screen.
3. Press the Play button.
4. Play the runner section.
5. After death, use the restart/end-screen flow.

## Controls

| Action | Input |
| --- | --- |
| Move | `A / D` or left/right arrows |
| Jump | `Space`, `W`, or up arrow |
| Roll | `Left Shift`, `Right Shift`, or `S` |
| Select character | click character card or press `1`, `2`, `3` |

## Character Roles

| Character | Ability |
| --- | --- |
| `PLAYER` | faster movement and stronger running feel |
| `SOLDIER` | one automatic revive after falling or landing in water |
| `ADVENTURER` | double jump |

## Expected Playable Result

The game should start from the Fox Dash main menu, let the player choose a character, enter the runner scene, move through generated platform sections, collect rewards, avoid hazards, and reach the end/game-over flow when the character dies.

## Do Not Upload These Unity Folders

The following folders are generated by Unity or local editors and should stay out of GitHub:

```text
Library/
Temp/
Logs/
UserSettings/
.vscode/
```

The repository `.gitignore` is set up to exclude these generated files.
