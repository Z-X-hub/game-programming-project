# Unity Solar System Kids

This is a classroom exercise for the Game Programming module.

## Purpose

This project is used to practise Unity scene creation, scripting, interaction, visual design and the basic game programming workflow.

This is not the final course project.

## Main Scene

The main scene is located at:

`Assets/SolarSystem/Scenes/MainScene.unity`

## Project Structure

- `Assets/` - Unity assets, scenes, scripts, materials, textures and audio
- `Packages/` - Unity package configuration
- `ProjectSettings/` - Unity project settings
